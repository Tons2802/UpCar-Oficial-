# 🚗 UpCAR Oficial - Landing Page de Alta Conversão

Este projeto é uma landing page desenvolvida com foco em conversão para venda de iluminação LED automotiva RGB.

A proposta é criar uma experiência direta, simples e altamente persuasiva, conduzindo o usuário até o WhatsApp para atendimento e fechamento da venda.

---

## 🎯 Sobre o Projeto

A UpCAR Oficial é uma operação digital voltada para o nicho automotivo, focada em produtos de impacto visual e alta demanda.

Esta landing page foi criada como parte de um modelo de negócio real, com objetivo de validar produto, gerar leads e realizar vendas através de tráfego pago.

---

## ⚙️ Funcionalidades

- Design responsivo (mobile-first)
- Interface moderna com identidade automotiva (dark + neon)
- Integração direta com WhatsApp (funil de vendas simples)
- Seção de prova e benefícios do produto
- FAQ interativo com JavaScript
- Estrutura otimizada para conversão

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)

---

## 📲 Funcionamento

Usuário acessa a página →  
Visualiza a proposta e benefícios →  
Clica no botão de ação →  
É direcionado para o WhatsApp →  
Atendimento e conversão em venda
